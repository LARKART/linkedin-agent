## Caption

Config files are usually the wall between a business owner and the automation they're paying for.

Claude Code just removed a piece of that wall. A new feature lets you change how the coding agent behaves by describing it in plain English, instead of editing settings files or writing config syntax.

That sounds like a small developer convenience. It isn't.

Most of the AI systems I build end up with a layer of configuration underneath: rules about tone, formatting, what to automate, what needs approval, how to handle edge cases. Right now, changing that layer usually means a developer opens a file and edits it.

If agent behavior can be adjusted through plain instructions instead, the person closest to the actual business process can shape how the system behaves without waiting on someone else to touch the code.

That's the direction agentic tools need to go. Not fewer humans in the loop, but less friction for the humans who should be in it.

The technical team still needs to design the guardrails. But the day-to-day adjustments shouldn't require a pull request.

Where in your workflows are non-technical people stuck waiting on someone else to make a small change?

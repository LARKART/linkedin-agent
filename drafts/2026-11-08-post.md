## Caption

Most agent demos skip the part that breaks production.

Nobody shows the cost.

Every tool call costs tokens.
Every retry costs tokens.
Every loop that runs one extra time costs money, and sometimes it runs a hundred extra times before anyone notices.

I've seen agents built with zero budget constraints.
No max iterations.
No cost ceiling.
No check that says stop here.

They work fine in testing because testing is short.

Then they go live, hit an edge case, and loop quietly for hours.

The fix is boring:

Set a hard limit on steps.
Set a hard limit on spend.
Log every tool call with its cost.
Build in a stop condition that isn't optional.

It's not exciting work.
It's the work that keeps an agent from becoming a surprise invoice.

If you're running agents in production, what's your stop condition?

## Caption

Anthropic announced an update to Claude Code Projects this week. A single project can now run multiple workers in parallel on related tasks instead of one agent handling one task at a time.

That is a real shift in how agentic coding tools get used.

Most of the automation work I do runs on the same principle, just outside of code. You break a workflow into parts that can run at the same time instead of waiting on each other. A lead gets enriched while the CRM record gets created. A document gets summarized while the notification goes out.

The bottleneck was never the AI model. It was always the orchestration around it, deciding what can run in parallel and what has to run in sequence because one step depends on the output of another.

If this holds up in practice, teams building with Claude Code will need to think less about prompting a single agent well and more about structuring work so multiple agents do not step on each other. Shared context, task boundaries, and conflict handling become the actual engineering problem.

That is the part that does not show up in a product announcement but ends up mattering most once you try to run it for real.

## Caption

Writing code was never the slow part for most teams.

The slow part is everything after: opening a PR, waiting on review, fixing comments, waiting again, merging, shipping.

Anthropic's new Claude Ship is aimed at that stretch. Not generating code, but moving it through review, fixes, and deployment with less manual back and forth.

That's a different problem than what most AI coding tools have targeted. Copilot and the first wave of agentic coding assistants focused on getting code written faster. The bottleneck just moved downstream, into review queues and release cycles.

If Claude Ship actually closes that gap, the interesting shift isn't "AI writes code now." It's that the last mile of software delivery, the part full of waiting and handoffs, becomes something a system can own with a human checking the output instead of producing every step of it.

That matters for small teams especially. A lot of them don't have a dedicated release engineer. The PR sits there because everyone is busy, not because the code is bad.

Worth watching whether this holds up once it's running against real production pipelines instead of demos. Shipping software has more edge cases than writing it.

What's eating more time on your team right now, writing the code or getting it through review and out the door?

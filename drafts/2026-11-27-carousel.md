## Caption

Google wants AI agents to go through its own MCP servers for Workspace.

But according to a report circulating this week, the Gmail MCP server doesn't expose a send function. No send action. On an email tool.

I haven't verified this myself, but if true, it's worth sitting with.

An MCP server isn't an integration. It's a list of tools the model is allowed to call. Official doesn't mean complete. Connected doesn't mean usable.

This matters for anyone building agent workflows on top of a platform's own MCP implementation. You're not building on what the brand promises. You're building on whatever functions actually show up in the tool list.

I've seen the same pattern with CRM and calendar integrations long before MCP existed. The API documentation says one thing. The actual scopes and endpoints available say another.

So before wiring an agent to any MCP server, Workspace or otherwise, the first step isn't architecture. It's reading the tool list line by line and checking what's actually callable.

If you're working with MCP right now, what have you found missing that you expected to be there?
